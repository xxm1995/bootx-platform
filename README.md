## 🍈项目介绍
- 后端使用Spring Boot 3.x + Jdk21 + Postgresql技术栈
- 使用 [Vben-Admin](https://vvbin.cn/doc-next/) 作为脚手架
- 移动端使用 [Taro](https://taro.jd.com/)、[NutUI](https://nutui.jd.com/) vue3+TS为技术栈。
